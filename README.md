# vendor-xlsx

Mirror of the SheetJS `xlsx` tarball, originally published at
<https://cdn.sheetjs.com/xlsx-0.20.3/xlsx-0.20.3.tgz>.

**Do not delete, rename, or make this repository private.** Published
versions of `@sheetxl/io` (0.3.8 through 0.7.27) depend on this exact URL:

```
https://raw.githubusercontent.com/sheetxl/vendor-xlsx/main/xlsx-0.20.3.tgz
```

Installs of those versions fail if the URL stops resolving, and lockfiles
pin the tarball's hash, so the file must also stay byte-identical:

```
sha512-oLDq3jw7AcLqKWH2AhCpVTZl8mf6X2YReP+Neh0SJUzV/BdZYjth94tG5toiMB1PPrYtxOCfaoUCkvtuH+3AJA==
```
